# Security Policy

## Supported versions

Security fixes are currently considered for the latest development version on
the default branch. Stream Agent is experimental; do not expose its local
inference server to an untrusted network.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's
private vulnerability reporting for this repository when available. If private
reporting is not enabled, contact the repository maintainer through the
verified contact route on the repository profile and include reproduction
steps, affected versions, and impact. Do not send credentials, model weights,
or signed download URLs.

We will acknowledge reports as soon as practical, investigate the issue, and
coordinate a fix and disclosure timeline with the reporter.
